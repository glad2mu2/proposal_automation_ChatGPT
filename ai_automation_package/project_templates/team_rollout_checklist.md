## 3. 프로젝트 운영

| 항목 | 기준 |
|---|---|
| Project 생성 단위 | 1개 입찰/제안 프로젝트당 1개 |
| Project 이름 | `YYMM_프로젝트명_CM_RFP분석` |
| 자료 업로드 | RFP, 과업내용서, 평가기준, 현장/영업자료, 초안 |
| 산출물 저장 | 프로젝트 폴더와 사내 서버 DB에 동일 명칭으로 저장 |
| 책임자 | 전략사업그룹 담당 PM |
