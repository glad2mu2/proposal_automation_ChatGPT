# 파일럿 운영 Runbook

## 목적

최근 완료 프로젝트 3건과 진행 예정 프로젝트 2건으로 AI 산출물의 정확도, 실효성, 팀원 재현성을 검증합니다.

## 대상 선정

| 유형 | 기준 | 건수 |
|---|---|---:|
| 최근 완료 | 심사결과, 실제 질의응답, 최종 제안서가 확보된 프로젝트 | 3 |
| 진행 예정 | RFP 접수 후 D-20~D-15 구간에 있는 프로젝트 | 2 |

## 진행 절차

### 1. 완료 프로젝트 사후 검증

1. ChatGPT Project를 생성합니다.
2. RFP, 평가기준, 최종 제안서, 발표안, 실제 질의응답, 심사결과를 업로드합니다.
3. RFP 분석 GPT로 필수조건, 감점요소, 평가배점, 4대 특성을 재분석합니다.
4. 발표 Q&A GPT로 예상 질문 50개를 생성합니다.
5. 실제 질문과 AI 예상 질문의 일치/유사 여부를 평가합니다.
6. `output_templates/pilot_evaluation_scorecard.md`에 점수를 기록합니다.

### 2. 진행 프로젝트 실전 검증

1. D-20~18: RFP 분석표와 KOM 요약자료를 생성합니다.
2. D-18~16: 기술지원 요청서를 생성하고 실제 기술지원 요청 메일에 반영합니다.
3. D-14~8: 제안서 초안 Review GPT로 1차/2차 리뷰를 실시합니다.
4. D-8~3: 발표 Q&A GPT로 예상 질문, 3x3 키워드 Sheet, 모범답안을 생성합니다.
5. 제출 후 실제 사용 시간을 기록하고 개선사항을 회고합니다.

## 평가 기준

| 항목 | 합격 기준 |
|---|---|
| RFP 필수조건 | 사람이 확인한 필수조건의 95% 이상 추출 |
| 감점/실격요소 | 치명 항목 누락 0건 |
| 평가배점 대응 | 주요 배점항목별 대응 전략 존재 |
| Review 품질 | P0/P1 수정사항이 실제 리뷰와 유사 |
| Q&A 품질 | 실제 질문 또는 유사 질문 30% 이상 포함 |
| 재현성 | 다른 팀원이 같은 입력으로 유사 산출물 생성 가능 |

## 회고 질문

- AI가 놓친 RFP 조건은 무엇인가.
- 사람이 수정한 핵심 판단은 무엇인가.
- GPT 지침에 추가해야 할 금지사항이나 출력 형식은 무엇인가.
- 팀원이 반복해서 헷갈린 사용 절차는 무엇인가.
- 다음 프로젝트부터 기본 적용할 산출물은 무엇인가.
