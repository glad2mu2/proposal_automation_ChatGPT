# GPT Builder 설정 가이드 v2

이 가이드는 실제 `CM PJT` 자료 분석 결과를 반영한 버전입니다. GPT Builder에서 부서 공용 GPT 3개를 만들 때 아래 파일의 내용을 Instructions에 붙여 넣고, 필요 자료를 Knowledge로 업로드합니다.

## 1. RFP 분석 GPT v3

### Instructions

`gpt_instructions/rfp_analysis_gpt_v3.md` 내용을 그대로 사용합니다.

### Knowledge 권장 자료

- 기술제안서 작성 절차서 매뉴얼
- 최근 CM 프로젝트의 RFP, 과업지시서, 평가기준
- 기존 RFP 제안전략설계서 샘플
- 기술지원 요청서 샘플
- 프로젝트 특성 분석 샘플

### 첫 질문 예시

```text
업로드한 RFP, 과업지시서, 평가기준을 기준으로 먼저 자료 품질과 OCR 가능 여부를 확인해줘.
이후 필수조건, 감점요소, 평가배점 대응 Matrix, Hidden Needs, Win Theme, 과업내용-개선전략 매핑표를 작성해줘.
불확실한 항목은 추정하지 말고 원문 확인 필요로 표시해줘.
```

## 2. 제안서 Review GPT v3

### Instructions

`gpt_instructions/proposal_review_gpt_v3.md` 내용을 그대로 사용합니다.

### Knowledge 권장 자료

- 기술제안서 작성 절차서 매뉴얼
- RFP 분석 결과
- 평가배점 대응 Matrix
- 과업내용-개선전략 매핑표
- 제안서 Review 리포트 샘플
- 최근 우수 제안서 목차 및 Q&A 샘플

### 첫 질문 예시

```text
업로드한 제안서 초안을 RFP와 평가기준 기준으로 검토해줘.
평가배점 Coverage, 과업내용 대응 여부, 누락/감점 위험, 일반론 문장, 정량화 부족, Change/Claim Control 부족을 우선순위별로 정리해줘.
수정 문장 예시는 바로 제안서에 옮길 수 있는 형태로 작성해줘.
```

## 3. 발표 Q&A GPT v3

### Instructions

`gpt_instructions/presentation_qa_gpt_v3.md` 내용을 그대로 사용합니다.

### Knowledge 권장 자료

- 기술제안서 작성 절차서 매뉴얼
- RFP 분석 결과
- 최종 제안서
- 발표안
- 실제 심사 질문 및 답변 기록
- 프로젝트별 리스크/쟁점 목록

### 첫 질문 예시

```text
업로드한 RFP, 평가기준, 제안서, 발표안을 기준으로 발표 예상질문을 만들어줘.
평가항목별 질문, 압박 질문, 근거 질문, 대안 질문을 포함하고, 각 질문마다 3x3 키워드와 4-Step 모범답안을 작성해줘.
답변은 발표자가 60초 안에 말할 수 있는 밀도로 작성해줘.
```

## 팀 운영 규칙

1. GPT가 원문 근거를 확인하지 못한 항목은 `확인 필요`로 표시하게 합니다.
2. 모든 프로젝트는 `00_자료품질_OCR_확인` 채팅을 먼저 생성합니다.
3. 산출물명은 프로젝트별로 동일하게 맞춥니다.
   - `RFP 제안전략설계서`
   - `평가배점 대응 Matrix`
   - `과업내용-개선전략 매핑표`
   - `제안서 Review 리포트`
   - `발표 예상 Q&A`
4. 실제 심사 후 질문과 AI 예상 질문의 적중 여부를 기록합니다.
5. 파일럿 5건 후 GPT Instructions를 한 번 더 개정합니다.
