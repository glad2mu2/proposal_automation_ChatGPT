# 기술지원 업무협조 요청서

## 사용 목적

RFP 제안전략설계 단계에서 Kick-Off Meeting에 필요한 기술지원 자료 초안을 만들기 위한 템플릿입니다. RFP 제안전략설계서의 `프로젝트 기본정보`, `Pass/Fail 조건`, `Hidden Needs`, `핵심 리스크`, `Win Theme`, `기술지원 요청 Item`, `PM 확인 필요 사항`을 재사용해 작성합니다.

Word 양식 파일이 함께 제공된 경우에는 아래 한글 파일명을 참조 템플릿으로 사용합니다.

- `기술지원 업무협조 요청서_양식.docx`
- `분야별 기술지원 요청내용 요약_양식.docx`

생성되는 Word 결과물 파일명은 반드시 영문 소문자, 숫자, `_`만 사용합니다.

- `technical_support_request_draft.docx`
- `technical_support_request_summary_draft.docx`

중요등급은 RFP 제안전략설계서의 우선순위를 기준으로 변환합니다.

| 우선순위 | 중요등급 |
|---|---|
| P0 | A+ |
| P1 | A |
| P2 | B |
| 보류/추가 확인 | Holding 또는 확인 필요 |

보고서에 없는 프로젝트 No., 단장, 제안 담당 PM, 관련 자료 위치, 내부 기한, 담당자명은 임의 추정하지 말고 `확인 필요`로 표시합니다.

## 5. 작성 시 유의사항

- 기존(일반) -> 제안(개선) 구조로 작성합니다.
- 적용 위치, 물량, 길이, 면적, 개소, 절감률, 절감금액, 공기단축 기간 등 수치화 가능한 항목을 포함합니다.
- 현장/도면/RFP 검증 근거를 명시합니다.
- A+급 핵심 Item은 우선 작성합니다.
- 기술지원 요청은 제안서에 들어갈 Evidence를 확보하기 위한 것이므로, 단순 검토 의견보다 `수치`, `비교표`, `프로세스`, `도식화 가능한 근거` 중심으로 요청합니다.
