# RFP 제안전략설계 체크리스트

## 사용 목적

이 템플릿은 RFP를 단순 요약하기 위한 표가 아니라, `rfp_strategy_design_report.docx` 작성 전에 핵심 판단을 빠짐없이 정리하기 위한 전략설계 워크시트입니다.

작성 흐름은 아래 순서를 따릅니다.

```text
자료 품질 확인 -> Pass/Fail 조건 -> 평가구조 해석 -> 발주자 문제 정의 -> Hidden Needs -> 핵심 리스크 -> Win Theme -> 제안서 목차/페이지 구성 -> 기술지원/KOM
```
